# Padronagens

Cinco ladrilhos próprios formam o vocabulário de padrões da marca; os arquivos estão no grupo de assets `Padronagens`.

**Quando usar**
- Dentro do casaco do `Personagem`, sempre recortado pela silhueta.
- Como fundo de campanha, site e embalagem de imagem.

**Regras**
- Uma padronagem por personagem; no máximo duas por arte.
- `Listra Toldo` é a principal: abre cada temporada.
- Não altere as cores de um ladrilho; para outra combinação, desenhe um novo e registre aqui.
- Nunca como estampa corrida na peça: a Reserva INK imprime só área localizada.
- Escala na estampa: a listra ou a casa deve ter pelo menos 4 mm impressa, para não virar textura.
